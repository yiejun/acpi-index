What this is
ACPI tracks how expensive AI compute is — like a stock index, but for renting GPUs and using AI models. It mixes four signals: GPU rental prices, AI model API prices, data-center electricity, and market sentiment.

How to read this: Top cards show today's raw prices. The charts below use formal statistics from the methodology paper (z-scores, weighted dot product, PCA) — they activate after 7 snapshots of data.
