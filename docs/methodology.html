METHODOLOGY · VERSION 1.0

What the number actually means.

ACPI measures changes in a fixed set of publicly quoted GPU rental and API prices in USD. It is an experimental quote-price index, not a tradable asset, transaction-price index or forecast.

FormulaTry an exampleBasket rulesData qualityStatistics

1. Compare each price with itself.

Dividing today's price by its own base-date price removes the units. A GPU-hour and a million tokens can then be combined as relative changes, without adding incompatible dollar prices.

Price ratio Rᵢ,t = Pᵢ,t / Pᵢ,base

If a GPU costs $4 today and $5 at the base, its ratio is 0.80: a 20% price decrease.

2. Combine fixed price ratios.

Layer index Lₜ = 100 × ∏ᵢ (Pᵢ,t / Pᵢ,base)wᵢ
ACPIₜ = 100 × (GPUₜ / 100)0.70 × (APIₜ / 100)0.30

Each layer's weights sum to 1. GPU providers have equal 25% shares, split equally among their fixed quotes; each of the three API models has a ⅓ share. The 70/30 composite weights are project choices, not estimates of global spending. They stay fixed across the entire published series.

This is a fixed-weight geometric price index. It is not a Törnqvist index: that formula uses the average expenditure shares from two periods. Geometric aggregation describes price-relative movement; an individual user's invoice depends on actual usage and contract terms.

3. Measure a change over a period.

Change (%) = 100 × (Iₜ / Iₜ₋ₖ − 1)

100 → 90 → 95 means 5% below the base, but 5.56% above the previous value. Seven-day and 30-day changes use calendar days, not seven or 30 scraper runs.

The basket is fixed and inspectable.

The committed analysis/basket.json records membership, base prices, base date and weights. The initial base is the first observed UTC date with all four GPU providers and all three API models. Subsequent builds reuse the file and never silently replace a missing member or redistribute its weight.

  • AWS: p5.48xlarge, 8 H100 80GB GPUs, Linux/shared on-demand; N. Virginia and Oregon. Instance price is divided by 8.
  • Azure: Standard_ND96isr_H100_v5, 8 H100 SXM GPUs, Linux on-demand; eastus, westus2, westus3. Instance price is divided by 8.
  • Lambda: fixed H100 SXM configurations identified by the original specification text. PCIe and other GPU types are excluded.
  • CoreWeave: fixed H100 HGX configuration identified by specification text. Node price is divided by the explicit GPU count.
  • API: OpenRouter quotes for GPT-4o, Claude Sonnet 4.6 and Gemini 2.5 Flash. They are fixed models, not claims of identical quality or current flagship status.
API quote = (2 × input $/M + output $/M) / 3

The API mix is two input tokens per output token, per million total tokens, with no cache/batch discounts. OpenRouter routing quotes can differ from direct-provider tariffs. GPU quotes include different CPU, RAM, storage and networking resources: v1 tracks like-for-like changes within each quote, not perfectly identical services across vendors. Prices do not guarantee availability.

Model retirement, configuration-text changes and region changes require a reviewed basket version. For replacements, preserve the previous series and link the new basket at an overlap date. Do not delete the manifest to make a broken member disappear.

Observation time is not publication time.

  • One observation per item per UTC day: the last valid collected quote, rather than an average weighted by scraper frequency. Today's close remains provisional.
  • Missing quotes may carry forward for at most seven calendar days and are visibly marked. After that the affected layer and composite become unavailable. Membership is never reweighted to the remaining quotes.
  • The seven-day carry limit is a project policy, not proof that a stale quote remains purchasable. Check the displayed timestamp.
  • EIA source month and collection time are preserved per state. A new monthly release never erases previously collected months.
  • Equities use individual closes. New collection records include the actual quote date; old records without it remain explicitly labeled.
  • Historical v1 observations are rebuilt from saved raw quotes. They replace the old PCA-weighted dashboard series and are not evidence of independently validated transaction prices.
  • Daily composite moves greater than 20% trigger review; they are flagged rather than automatically removed.
  • Collector checks require fresh required providers. Critical build/test/export steps fail the workflow on errors. A green workflow means the automated checks passed, not that every source tariff was independently audited.

Price level, momentum and recent rank differ.

Recent price rank: rank the current index among complete observations in the last 90 calendar days. Below 50 means lower than the center of recent history. Equal-price ties are centered; a flat series scores 50. At least seven valid observations are needed. A low rank is not a fair-value or buying recommendation.

Rank = 100 × (count below + ½ × count equal) / valid count

Z-score: distance from the trailing daily mean in standard deviations, not a rate of change. With no meaningful variance it is undefined.

z = (today's index − trailing mean) / trailing standard deviation

Drawdown: the percentage below the highest index observed since the base, not a guaranteed historical market peak.

Drawdown = 100 × (Iₜ / max(I₀ … Iₜ) − 1)

Contributions: GPU and API weighted log changes sum exactly to the composite log change. They are labeled log-percent units, not ordinary percentage points.

cᵢ = 100 × wᵢ × ln(Lᵢ,t / Lᵢ,t−1)
ordinary change (%) = 100 × (exp(Σcᵢ / 100) − 1)

Correlation & PCA: trailing 30-day daily returns, at least seven paired observations. Constant dimensions are excluded from PCA; fewer than two varying dimensions yields unavailable. Each PCA fit uses only information collected by that date. These are exploratory signals, never index weights or a “master price.”
